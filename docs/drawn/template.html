Nimblecube, Drawn

You asked whether the space is a sphere or a cube. It is both. Every hypervector is a corner of a 4096-dimensional cube, and all of those corners sit on one sphere.

A cube, with a sphere through its corners

Draw it with 3 bits instead of 4096. Each bit is one direction, so 3 bits make an ordinary cube with 8 corners. Every corner is the same distance from the centre, so all 8 touch one sphere.

Hamming distance is simply how many edges you walk to get from one corner to another. A fitting picture, for a project called nimblecube.

Where the size is set

One line. Every vector, table and distance in the project follows from it.

// nimblecube-core/src/hv.rs, lines 4 and 6
pub const DIM_BITS: usize = 4096;
pub const WORDS: usize = DIM_BITS / 64; // 64 words of 64 bits = 512 bytes
  • RoomNever the limit. 24096 is about 101233 corners, while the observable universe holds about 1080 atoms.
  • ResolutionThe real limit. Unrelated corners wobble ±32 bits around 2048, and that wobble decides how many different things you can tell apart.
  • Turn the dialSet DIM_BITS to 1024 and the radius becomes 32, the wobble ±16, and every vector 128 bytes instead of 512.

Why unrelated things are all the same distance

Pick any corner as your baseline. Almost every other corner sits 2048 bits away, give or take 32. That thin band is the whole trick: real readings that resemble your baseline land far inside it, and chance almost never reaches there.

Huddles and nets

Similar things huddle together. A bundle is the middle of a huddle: a single point that leans towards every member at once. RejectNet throws one net around the normal huddle, so one comparison tells you whether a reading is anywhere near normal.

The three moves

Everything nimblecube does is built from three operations on those corners.

The same view from every corner

XOR every corner with the same vector and each one moves somewhere new, yet every distance between them stays exactly as it was: d(x ⊕ v, y ⊕ v) = d(x, y), because the v cancels out. The right v can carry any corner onto any other, so every corner has to see the same view. There is no special place anywhere in the space.

Bind and permute are both moves like this: they relocate everything without stretching anything. Bundle is the only move that breaks the symmetry, by making one spot special, the middle of a huddle. That is why it is the move that creates memory.

What runs where

The line this project keeps coming back to: heavy trained work above it, fast integer memory below it.
